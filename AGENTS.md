# AGENTS.md

Le Sserafim archive helper: an ASP.NET Core 9 API plus a SvelteKit SPA that ingests a Google Sheets event archive and Google Drive image folders into SQLite. Live at https://ssera.estral.fi.

## Layout

- `src/Ssera.sln` — API + Client. There are no test projects.
- `src/Ssera.Api` — minimal API (`Program.cs`), EF Core + SQLite, ingestion workers (Google APIs) in `Ingestion/`, endpoints in `Features/<Area>/`.
- `src/Ssera.Client` — SvelteKit 2 / Svelte 5 / TypeScript, built through an `.esproj` in the solution.
- `src/Ssera.Shared` and `src/Ssera.Client/bin|obj` are stale Blazor-era leftovers (untracked, not in the solution). Ignore them.

## Commands

- `dotnet build src/Ssera.sln` — builds the API **and runs `npm install` + `vite build`** for the client (Node required).
- `dotnet build src/Ssera.Api/Ssera.Api.csproj` — API only, much faster.
- `dotnet run --project src/Ssera.Api/Ssera.Api.csproj` — listens on http://localhost:5192 and https://localhost:7224; `/` redirects to Scalar docs at `/scalar/v1`.
- Client (from `src/Ssera.Client`): `npm ci`, `npm run dev`, `npm run check` (svelte-check), `npm run lint` (prettier).
- Client needs `.env` with `PUBLIC_API_DOMAIN` (copy `.env.example`); `src/lib/ApiHelper.ts` throws at import without it.

## Known pre-existing failures

- `npm run check` fails: TS error in `src/lib/components/ListFilters.svelte:196` plus one warning. Use it to catch new errors, not as a green gate.
- `npm run lint` fails on ~28 tracked files; the repo is not prettier-clean. `npm run format` would create a large unrelated diff.
- No tests exist; verification is `dotnet build` plus `npm run check`.

## API conventions

- Endpoints are source-generated by Immediate.Apis / Immediate.Handlers / Immediate.Validations. A feature is a `sealed partial class` in `Features/<Area>/` with `[Handler]` + `[MapGet("/api/...")]`, a nested `[Validate]` request record implementing `IValidationTarget<T>`, and a static `HandleAsync`. `Program.cs` only calls the generated `AddSseraApiHandlers()` / `MapSseraApiEndpoints()` — never register routes manually.
- Reuse a handler from code by resolving the generated nested type, e.g. `AddHistory.Handler` (both workers do this).
- API enums serialize as strings; the client hand-maintains mirror types/enums in `src/lib/*ApiHelper.ts`. No codegen exists, so update both sides.
- Config is read with `GetRequiredValue` / `GetRequiredParsedValue` and throws on missing keys. Keys: `ConnectionStrings:Sqlite`, `GoogleApiKey`, `WorkerDelay` (seconds), `CorsAllowOrigins` (non-dev only). `GoogleApiKey` belongs in user-secrets (UserSecretsId is set).
- Migrations are applied automatically at startup, so the gitignored `src/Ssera.Api/sqlite.db` is recreated by running the API. Add schema changes with `dotnet ef migrations add <Name>` from `src/Ssera.Api`. Entity config (indexes, etc.) lives in nested `Configuration : IEntityTypeConfiguration<T>` classes.
- `EventArchiveWorker` and `ImageArchiveWorker` start with the host, poll Google Sheets/Drive, and replace whole tables. A placeholder `GoogleApiKey` just logs failures; the default `WorkerDelay` of 99999 keeps polling effectively off.
- Style is build-enforced via `Directory.Build.props` (`AnalysisLevel=latest-all`, `EnforceCodeStyleInBuild`) and `src/.editorconfig`: file-scoped namespaces, `is null`, `var`, `_camelCase` private fields, `_` discards for unused results.

## Client conventions

- SPA only: `src/routes/+layout.ts` sets `ssr = false`.
- Newer components use Svelte 5 runes (`$state`, `$props`, `$bindable`), but `+layout.svelte` still uses legacy `<slot>` — mixed styles.
- Prettier settings: tabs, double quotes, trailing commas, print width 100. No ESLint.

### Razor markup formatting (`src/Ssera.Client/**/*.razor`)

- 4 spaces per level, spaces only, no tabs.
- Elements with 0–1 attributes and short content stay on one line.
- Elements with 2+ attributes are exploded: tag name alone on its line, one attribute per line indented one level deeper than the tag, `>` / `/>` on its own line back at the tag's indentation, text content one level deeper, closing tag at the tag's indentation.
- Razor directives (`@bind`, `@bind:after`, `@onclick`, `@key`, `@ref`, ...) count as attributes.
- Blank line between sibling elements when either sibling is exploded.
- Literal `<` / `>` in rendered text are written `&lt;` / `&gt;`.

## Deploy

- `.github/workflows/docker-build-and-push.yml` is manual (`workflow_dispatch`) and only builds/pushes `ghcr.io/svee4/ssera.api` and `.client`; CI runs no tests or checks.
- The production API sits behind a trusted reverse proxy (ForwardedHeaders, `ForwardLimit = 1`) and restricts CORS to `CorsAllowOrigins`; the client image runs `node build` (adapter-node).
